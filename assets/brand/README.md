# DriveLegal Motion D

The current app icon is a sculpted amber road ribbon forming a D, with a forward chevron in its center, on a near-black rounded tile. The lane markings connect the monogram to the road-safety project. Tonal depth is baked into a static image: there are no animations, shaders, live blur, or ongoing rendering effects.

- `drivelegal-motion-d-master.png`: preserved image-generation master.
- `drivelegal-motion-d.png`: optimized 512px static app/export asset.
- `drivelegal-logo.png`: current logo alias.
- `motion-d-prompt.txt`: exact brief and generation provenance (built-in image_gen).
- `drivelegal-road-shield-archived.png` and `drivelegal-logo.svg`: previous shield design, kept as an archive.
- Android resources provide the app artwork, adaptive launcher, and a simplified matching monochrome D.

The separate Google provider icon comes from Google's official artwork at https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg. Its original copyright notice is retained in `google-sign-in.svg`.
