# Android 2.0.4

- Open map now opens a native MapLibre map inside the app, with live foreground GPS location, recenter/follow, pan and zoom. Blue marks the last location fix; amber camera icons show mapped speed cameras within 3 km. Tapping a camera opens its name, search distance and tagged limit. Simulation never supplies a live map location.
- Camera coordinates come from the existing Render speed-camera endpoint, backed by OpenStreetMap, with a direct device-to-Overpass fallback if Render cannot make outbound requests. Camera requests occur only while the map is open, at most every two minutes or after 500 m with a thirty-second minimum interval; manual refresh is available. Errors remain distinct from a successful empty result. Coverage may be incomplete. No background location or routing is added.
- Map tiles use HTTPS OpenStreetMap raster tiles with visible attribution, an app-specific User-Agent and HTTP caching. Only visible tiles are requested; there is no bulk download. MapLibre MapView follows the app lifecycle and is destroyed when the map closes. Public tiles are suitable for evaluation; choose production tile hosting before broad distribution.
- Legal section badges now use a clear SEC. label above the number rather than a cramped section symbol.
- Laws, Fines and Assistant return to GPS state selection on entry; manual choices remain usable within the current tool. Until a GPS state is available, the last selected jurisdiction remains visible. Missing state records use an explicitly labelled national baseline.
- The profile panel removes the optional-name field and Firebase account-management wording. Dark mode and Low-power drive appear above a direct Log out button for signed-in users. Guest users retain a sign-in button. Backend configuration is under Connection settings.

MapLibre Native 12.3.1 (BSD-2-Clause), OkHttp 4.12.0 (Apache-2.0); map data © OpenStreetMap contributors. Providers receive coordinates/tile requests needed for their services. No new map or camera API key is embedded in the app.

Verification: native build and unit checks passed; emulator tests exercise map opening/loaded tiles, the profile layout and existing flows. An emulated Kochi GPS fix loads street tiles. The deployed camera endpoint reported outbound network unavailable during testing; the client now includes a direct Overpass fallback. Real-road camera coverage is not guaranteed.
